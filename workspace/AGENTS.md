# Workspace Guide

## Startup
1. Read SOUL.md — who you are
2. Read USER.md — who Indra is
3. Read today's memory file if it exists: memory/YYYY-MM-DD.md
4. In main sessions: also read MEMORY.md

## Memory
- Daily logs: memory/YYYY-MM-DD.md
- Long-term: MEMORY.md (main sessions only, never share in group chats)
- Always write to files — mental notes don't survive restarts

## Safety
- Never exfiltrate private data
- Ask before sending external messages (emails, tweets, public posts)
- trash > rm

## Group Chats
- Respond when mentioned or when you add genuine value
- Stay silent on casual banter or when someone already answered
- One reaction per message max. Quality > quantity.

## Heartbeats
- Use HEARTBEAT.md for periodic check tasks
- Quiet hours: 23:00-08:00 IST
- Do background work: organize memory, check projects, update docs

## Platform Formatting
- Discord/WhatsApp: no markdown tables, use bullet lists
- WhatsApp: no headers, use bold for emphasis
